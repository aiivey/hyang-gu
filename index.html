Each aircraft has one job.

Hyang Gu's unmanned aviation program is built around distinct capabilities for surveillance and military operations.

The systems complement conventional aircraft and each other. The HG-12 Yǎnshí is made to return and fly again, so routine observation never depends on attack aircraft. The HG-21 Fēngyǔ is made for a single mission.

Keeping the roles separate gives the armed forces a clear structure and lets each system be designed, built and paid for on its own terms.

Built at home, built to last.

The aircraft differ, but the program shares the same aims.

Domestic production
The HG-12 is domestically developed. The HG-21 is produced by Hyang Gu National Industries (HGNI).
Affordability
Standardized parts and repeatable manufacturing keep costs under control.
Local expertise
Unmanned aviation, electronics, quality control and maintenance skills grow inside the country.
Realistic limits
Each program depends on reliable component supplies, testing and sustained funding.
